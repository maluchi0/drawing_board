# 인터넷 그림판 (Internet Drawing Board)

HTML5 Canvas 기반의 웹 그림판 애플리케이션입니다.

## 🎨 주요 기능

### 그리기 도구
- **선택 도구**: 오브젝트 선택 및 이동 (클릭/드래그 영역 선택)
- **자유 선택 도구**: 자유 곡선으로 영역 그려서 오브젝트 선택
- **펜**: 자유 곡선 그리기
- **지우개**: 그림 지우기
- **직선**: 직선 그리기
- **사각형**: 사각형 그리기
- **원/타원**: 원 그리기 (Shift/Alt 키로 타원 모드)
- **페인트**: 클릭한 오브젝트의 내부 색상 변경 (윤곽선은 유지)
- **스포이드**: 캔버스에서 색상 추출
- **텍스트**: 한글/영문 텍스트 입력
- **이미지**: 이미지 파일 불러오기

### 색상 및 스타일
- **전경색/배경색 분리**: 독립적인 전경색(윤곽선)과 배경색(채우기) 설정
- **색상 전환**: X 키로 전경색↔배경색 교체
- **색상 리셋**: D 키로 기본 색상(흑백)으로 복원
- 선 두께 조절 (1-20px)
- 투명도 조절 (0-100%)
- 폰트 크기 조절 (12-72px)

### 편집 기능
- 실행 취소 (Undo) / 다시 실행 (Redo)
- 전체 선택 (Ctrl+A)
- 선택된 오브젝트 삭제 (Delete/Backspace)
- 전체 지우기
- 캔버스 크기 조절 (사용자 정의 크기)

### 저장 및 공유
- **프로젝트 저장/불러오기**: 5개 슬롯에 작업 저장 (로컬 스토리지)
- PNG 이미지로 내보내기
- **PDF 생성**
- **공유하기** (imgur API 연동)
  - 이메일로 공유 (Canvas 이미지 URL 포함)
  - Twitter 공유 (실제 Canvas 이미지 표시)
  - Facebook 공유 (실제 Canvas 이미지 미리보기)
  - 기타 공유 (Web Share API, 모바일)
  - 로컬/인터넷 환경 모두 지원

### 오브젝트 관리
- 오브젝트 선택 및 이동
- 다중 선택 (Shift/Ctrl/Cmd + 클릭)
- 바운딩 박스 표시
- 선택된 오브젝트 삭제

## ⌨️ 키보드 단축키

- `Ctrl + Z`: 실행 취소 (Undo)
- `Ctrl + Y` 또는 `Ctrl + Shift + Z`: 다시 실행 (Redo)
- `Ctrl + A`: 모든 오브젝트 선택
- `Delete` 또는 `Backspace`: 선택된 오브젝트 삭제
- `X`: 전경색/배경색 전환
- `D`: 전경색/배경색 기본값으로 리셋
- `Shift/Ctrl/Cmd + 클릭`: 다중 선택
- `Shift/Alt + 드래그` (원 도구): 타원 그리기
- `Enter`: 텍스트 입력 완료
- `ESC`: 텍스트 입력 취소

## 🛠️ 기술 스택

- HTML5 (Canvas API)
- CSS3 (Flexbox)
- Vanilla JavaScript (ES6+)
- jsPDF (PDF 생성)

## 🌟 특징

- **Standalone 애플리케이션**: 서버 없이 브라우저에서 직접 실행
- **오브젝트 기반 렌더링**: 모든 그림 요소를 독립적으로 관리
- **로컬 저장소 활용**: 프로젝트를 브라우저에 저장하여 언제든지 불러오기 가능
- **한글 완벽 지원**: 텍스트 입력 시 한글 IME 지원
- **모던 브라우저 호환**: Chrome, Firefox, Safari, Edge 지원
- **반응형 디자인**: 다양한 화면 크기 지원
- **직관적인 UI**: Photoshop/GIMP 스타일의 전경색/배경색 시스템
